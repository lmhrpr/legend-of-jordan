# The Legend of Jordan

A Zelda / Golden Axe Warrior–style adventure made in GameMaker for Jordan's 40th.
Kid Jordan has to find his little brother Liam, who's gone missing.

## Opening the project

Open `TheLegendOfJordan.yyp` in GameMaker (2024.14 or later).

## Controls

| Key | Action |
|---|---|
| Arrows / WASD | Move |
| Z | Use the item equipped to Z |
| X | Use the item equipped to X |
| Enter | Talk, read signs, turn text pages, choose menu options |
| P / Esc | Pause and open the inventory (Z / X equip the selected item) |
